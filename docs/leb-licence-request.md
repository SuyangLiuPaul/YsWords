# LEB — permission request to Faithlife / Lexham Press

Drafted 2026-09-02. **Not sent.** Send from **support@yahwehword.com**.

This is a **separate letter to a separate publisher** — the Lexham English
Bible is Faithlife's (Lexham Press), not The Lockman Foundation's. Do not
combine it with `docs/nasb-licence-request.md`; a joint letter to either
one is a letter neither can act on.

Faithlife's permissions contact is via `lexhampress.com/permissions`
(and `permissions@faithlife.com` where a form is not offered — verify the
current address on their site before sending; it has moved before).

**Why this letter exists at all:** LEB has never been named in any
licensing note in this repository. Every write-up, including the one that
built the `/read/` prerender exclusion around this exact concern, said
NASB alone. LEB sat in the same directory, at the same exposure, for the
same reason, and nobody looked. It was measured on 2026-09-02 —
`/assets/assets/leb.json`, HTTP 200, 8,812,100 bytes — and removed from
the public web build the same day.

---

**Subject:** Permission request — complete LEB text in a free,
non-commercial Bible app

Dear Permissions Team,

I am writing to request permission to use the Lexham English Bible in
**Yahweh's Words** (yahwehword.com), a free Bible reader for Android,
iOS, Web, macOS, Windows and Linux, aimed principally at bilingual
Chinese-English readers.

The application is given away at no cost. There is no advertising, no
subscription, no in-app purchase, no paywall, and no sale or sharing of
user data. We are [a non-profit Christian ministry / an independent
ministry project — fill in your actual status], with no commercial
revenue of any kind.

Our use requires the **complete text**, because the reader lets a user
open any chapter and read it offline, and offers translations side by
side. I understand this is beyond what the LEB's general permission for
quotation covers, which is why I am writing rather than relying on it.

Until this week the complete LEB text was also downloadable as a single
file from our website, as a side effect of how the web build packages its
data. That has been removed as of 2026-09-02, pending your answer.

We would display the copyright notice and attribution in the form you
require — on the version-selection screen, in the app's About page, and
in the repository documentation — and would follow whatever restrictions
you set on caching, offline storage, export and text selection.

Would Faithlife be willing to grant a licence for bundling the complete
LEB within this free application for offline reading? If a licence of
that kind is not available for a project of this kind, we would be
grateful to know what is. If the answer is no, we will remove the LEB
entirely.

Thank you for your time.

With respect,

[Your name]
[Role / ministry name]
support@yahwehword.com
yahwehword.com

## Notes

**The LEB's terms are more permissive than the NASB's**, and this letter
may well come back yes where the other does not. That is a reason to send
it, not a reason to assume the answer — the permissive part is the
quotation allowance, and shipping the whole text as a file is a different
act from quoting it.

**Do not send this one to Lockman or that one to Faithlife.** They are
different publishers, different texts, different terms. The only thing
the two requests share is the sender.
