# 和合本雅偉版 繁體字裁決

2026-09-14。

## 一、字形：按香港

業主裁定「按照香港和合本的繁體字」。出版方自己的轉換說明也是這樣寫的：
「**Hong Kong**, at the church's request: 裏, 牀, 着 — not Taiwan's 裡,
床, 著」。

本倉的繁體先前走的是台灣那條路（只有 裏 是港式），現已改為港式。
十八個字，共 **15,108 處**：

| | | 次數 | | | 次數 |
|---|---|---|---|---|---|
| 說→説 | | 9,539 | 戶→户 | | 292 |
| 著→着 | | 2,647 | 悅→悦 | | 245 |
| 衛→衞 | | 1,262 | 臥→卧 | | 114 |
| 脫→脱 | | 418 | 床→牀 | | 80 |
| 群→羣 | | 323 | 其餘十個 | | 188 |

**每一對都是用本機的 `opencc` 兩個側寫跑出來核對的**，不是誰憑記憶列的：

```
printf '说着卫脱群户悦卧床钩税温启兑峰叙锐葱' | opencc -c s2hk
説着衞脱羣户悦卧牀鈎税温啓兑峯敍鋭葱
printf '说着卫脱群户悦卧床钩税温启兑峰叙锐葱' | opencc -c s2tw
說著衛脫群戶悅臥床鉤稅溫啟兌峰敘銳蔥
```

四個候選**沒有採用**，因為兩個側寫輸出相同，可見是選詞不是地區字形：
梁／樑（樑是橫梁，梁是人名地名）、痴／癡、灶／竈、麵／麪。

這**不是重新轉換**。整份跑一次 `opencc -c s2hk` 會把本倉自己的修訂一併
抹掉——創世記 41 的乾瘦、准許、指證，以及今天按和合本改回的五類。
只有這十八個字一對一地換，其他判斷原封不動。

## 三、三件必須留意的

**一、和合本自己並不一致，沒有替它抹平。** 出25:13 寫「做兩根槓」，
出27:10 寫「鉤子和杆子」——同一種物件，兩個字。所以「杠」這一類在
一節裡判我們錯、在另一節裡判我們對。上表每一行記的是**那一節**的讀法，
**不能當成全域替換**，必須逐處對著所引的那一節改。

**二、麽／麼 這一行的理由和別行不同。** 它是字形，照理應歸地區類，
但 HKVariants 和 TWVariants 裡都沒有它，而 OpenCC 的底表 `STCharacters`
直接把 么 映成 麼——也就是說港台任何一條路都產生不出我們的 麽。
兩個獨立證據（字典與台灣文本）都指向 麼。1,204 處，值得再看一眼。

**三、有 26 行根本不是字形分歧。** 箴22:11（8 行）、耶4:22（8 行）、
徒26:16（5 行）、耶7:14（2 行）、俄1:5（2 行）、耶12:14（1 行）
這六節，兩份文本**整節錯開一個詞**，比對程式就把每個錯位都報成一個
「字類」。那是經文差異不是轉換差異，要另外看那六節。

## 四、怎麼複驗

```
tools/audit_cuv_tr_against_official.py --report <路徑>   # 列出所有分歧
tools/apply_hk_variants_to_cuv_tr.py                     # 字形，按港式
tools/repair_cuv_tr_overconversion.py                    # 五類過度轉換
```

用詞那 128 類的裁決來自信望愛 `bible.fhl.net`（`VERSION4=unv`，繁體
和合本），逐節取原始位元組比對，不經任何摘要。
