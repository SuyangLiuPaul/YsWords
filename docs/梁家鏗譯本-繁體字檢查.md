# 梁家鏗譯本 繁體字檢查

2026-09-14。這份清單是給譯者的，不是給程式的。

## 檢查方法

這個譯本同時發行簡體與繁體兩個檔案，繁體是由簡體轉出來的。
所以不需要外部依據也能檢查：把兩個檔案逐字對齊，凡是兩邊不同的
位置，都是轉換器做過的一個判斷；同一個字它做了一千多次相同的判斷、
只有一兩次相反的判斷，那一兩次就是錯的。**轉換器自己就是指證自己的
證人。**

下面兩類是機械性的、沒有歧義的，程式已經照多數決修好；
列在這裡是為了讓您知道動過哪裡。

同一個檔案把 稣 轉成 穌 一千多次，只漏了這一處。

## 乙類：舊字形

意思沒有錯，但字形是舊的：説／說、啓／啟、証／證。
這一類影響的是**搜尋**——讀者打「說」找不到「説」——
而同一個檔案裡兩種字形是混用的，下面列的是少數的那一邊。

（衞／衛、羣／群、裏／裡 這一類**沒有列進來**，因為它們是港台
用字習慣的不同，不是新舊字形；貴方繁體印刷版用哪一種，我們就
跟哪一種。）

## 丙類：請譯者裁決的

這幾處程式沒有動，因為它們是關於**詞**的判斷，不是字形：

* **馬可福音 1:23**「在他們的會堂里」——應作「會堂裡」。
  檔案裡其他 45 個「里」都是對的（公里、提比里亞、克里特、
  堅革里…），所以「里」這個字本身不能一律掃換。
* **准許／準許**（馬可 5:13、8:30、10:4）——准 是允許，準 是準確。
  簡體本作「准许」，檔案自己也寫過 6 次「准許」。
* **蒙住／矇住**（馬可 14:65）——矇 用於眼睛，來源作「蒙住」。
* **指證／指証**（約翰 8:46）。

另外，下面這些位置的字在兩個檔案裡是一樣的，但同一個字在別處被
轉成了另一個形。它們**沒有被改動**——因為這些字在繁體裡本來就站得住
（約旦、走一里路、放在斗底下、與我何干），程式不該替您決定：

## 丁類：兩邊分節不同的九節

這一類與字形無關，是**經文本身**：官方站的版本與這裡的版本在
這九節切分不同，直接照搬會刪掉經文，所以一個字都沒有動。

| 出處 | 情況 |
|---|---|
| 馬太福音 21:44 | 這裡只有一個右引號，官方站有整句「那撞擊這石頭的必垮…」 |
| 路加福音 23:34a | 「父親啊，赦免他們」——官方站有，這裡沒有 |
| 約翰福音 12:36b | 官方站把「耶穌說完了這些話…」放在 36 節 |
| 羅馬書 3:10 | 官方站把「沒有義人，一個也沒有」放在 10 節 |
| 腓立比書 1:1 | 收件人一句兩邊落在不同節 |
| 哥林多後書 13:14 | **這裡有祝福語，官方站的 13:14 是空的** |
| 約翰一書 4:16 | 後半句歸屬不同 |
| 約翰三書 1:14 | 問安一段歸屬不同 |
| 啟示錄 12:17 | 末句歸屬不同 |

請問哪一種分節是您要的？
