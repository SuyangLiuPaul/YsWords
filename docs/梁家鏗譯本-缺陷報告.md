## ⚠️ 本報告先前兩處自己數錯 / 說錯的地方

**一、「簡體版 約翰一書 4:16 少了『神就是愛…』」——** 方向說反了。

兩份官方材料互相不一致，哪一份為定本是出版方的事，我們兩邊都不改。

**二、「117 節的節號被吞進上一節」——** 數錯了，實際是 **5 節**。
當時把 `<note:>` 註釋裡的經文出處（如「參11.6，13.57」）也算成了節號。
詳見第三節。

簡體版同樣有被吞的節號（路加福音三處），而且**簡體版缺了馬可福音

教訓：先查來源再相信差異；發現一處缺陷，先數完全部再下結論。

## 一、與官方簡體版的整體比對

| | |
|---|---|
| 可比對節數 | 4,826 |
| 完全一致（去除註釋標記後） | **4,731 節（98%）** |
| 用字確有出入 | **95 節（2%）** |

那 95 節看起來是**出版方後來的修訂**，而不是損壞。例如：

```
以弗所書 2:4
  官方：然而，神富有愛憐，出於他愛我們的大愛，
  我們：然而神滿有憐憫，因著他愛我們的大愛，
```

也就是說：**我們目前收錄的是較早的修訂版本。** 可用
`tools/proofread_biblexg.py` 逐卷列出全部 95 節。

那 95 節是**用字**的差異，與以下各節所述的**結構**問題無關。

## 二、整節缺失

### 繁體版原缺的 3 節 —— 已補回

`以弗所書 3:16`、`彼得前書 3:11`、`彼得前書 3:12`。三節的經文本來就在
我們的資料裡，只是被併進了上一節（見第三節）。已按**官方繁體印刷版**
《註釋本》2025 第二版的分節各自獨立成節，**經文一字未改**。

### 簡體版缺的 4 節 —— 缺在官方，不在我們

`馬可福音 6:8`、`6:9`、`6:10`、`6:11`。

**官方簡體電子版 `cn-mk.json` 本身就沒有這四節**，而且第 7 節在
「并授予他们权能」之後就斷了，缺「制服不洁的灵」。官方繁體印刷版
第 83-84 頁五節俱全，我們的繁體版也與印刷版逐字相符。

這不是古卷異文（與太 17:21 一類不同），各抄本皆有此段，因此是官方
電子版的遺漏。**我們不會自行把繁體轉成簡體補上** —— 那等於由我們代寫
經文。已列入 `docs/梁家鏗譯本-請教出版方.md` 向出版方查詢，並在
`test/biblexg_verse_integrity_test.dart` 裡把這四節釘成「已知缺口」，
一旦缺口擴大，測試會立刻失敗。

## 三、下一節的節號與經文被吞進上一節 —— 5 節，不是 117 節

**本報告先前寫「繁體 117 節、簡體 115 節」，那個數字是錯的**，特此更正。

當時的檢查把 `<note:>` 註釋內的經文出處也當成了節號 ——
`馬太福音 15:12` 的註釋是「參11.6，13.57」，裡面的 11、13、57 全被算成
了被吞的節號。剔除註釋後重數，全新約只有 **5 節**，藏著 **7 節** 經文：

| 位置 | 藏著 | 成因 | 狀態 |
|---|---|---|---|
| `路加福音 22:42` | 22:43、22:44 | 官方電子版 `affix` 上標 | ✅ 已分節 |
| `路加福音 23:16` | 23:17 | 同上 | ✅ 已分節 |
| `路加福音 23:33` | 23:34a | 同上 | ⏳ 待定（子節號） |
| `彼得前書 3:10` | 3:11、3:12 | 繁體轉換（僅繁體） | ✅ 已分節 |
| `以弗所書 3:15` | 3:16 | 繁體轉換（僅繁體） | ✅ 已分節 |

**成因**：官方電子版把「古卷或無」的經文放進
`<span class="affix"><sup>43</sup>…</span>`，節號是 `<sup>` 上標。
我們匯入時把上標壓成了正文，讀者於是看到

```
路加福音 22:42： “如果你願意，求你把這一杯拿開，但不要照我的意思，只要成就你的旨意。”43有一位使者從天上向他顯現，給他力量。44他在極度痛苦之中…
```

—— 正文裡多了個「43」，而且查路加福音 22:43 查不到。全新約只有三個
這樣的 `affix` 區塊，全在路加福音，已逐一核對。

繁體印刷版把這幾節照常編號並加註（「43-44節註：最古的抄本並沒有
43-44節，但許多其他抄本有，參 NA28、UBS5、TC」），所以按印刷版分節。

`路加福音 23:34a` 尚未處理：印刷版作 `34a` / `34b` 兩個子節號，官方電子版
把後半仍編為 `34`。改節號會牽動程式裡的經節識別碼（收藏、筆記靠它跨版本
對應），需要先定案再動。

## 四、僅註釋不同、經文相同（4 節，供參考）

這幾節的經文本身兩版一致，只是 `<note:>` 註釋一版有一版無，
列出以免被誤認為經文缺失：

- `以弗所書 3:12`、`使徒行傳 8:5`、`路加福音 9:17`、`路加福音 9:46`

## 五、YsWords 已自行修正的部分

只更動編號與分節，**未改動任何經文文字**：

- `馬太福音 16:13` 原被標成 `16:3`，另有一個標成 `16:1` 的空行。
  因此該節查不到，而 `16:3` 會回傳兩段互相矛盾的經文。
  依簡體版對照更正後，該章恢復為 1-28。
- `使徒行傳 15:16` 原被拆成兩行、共用同一節號，依簡體版合併為一節。
- 上述第三節的 5 處分節，依官方繁體印刷版《註釋本》。

## 六、這份報告怎麼驗證

`test/biblexg_verse_integrity_test.dart` 會在每次 `flutter test` 時檢查：
正文裡沒有被吞的節號、沒有重複的經節、沒有空節、每章 1..n 的缺口
只限已知且有理由的那些（古卷或無、合併節號、以及馬可福音 6:8-11 這個
官方缺口）。把本次修正前的資料放回去，這個測試會立刻失敗。
