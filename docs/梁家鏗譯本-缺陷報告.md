# 梁家鏗譯本（第二版）資料缺陷報告

由 YsWords 將繁體版與簡體版逐節比對得出，2026-08-10。
兩個版本互為對照——**每一項都是其中一版有、另一版沒有**，因此
可以確定是轉換過程的損壞，而不是譯本原意。

> 我們不會自行補寫任何經文。跨繁簡補字就是猜測，對聖經不能猜。
> 因此以下只是報告，懇請提供原始檔案。

---

## 一、最要緊：簡體版 約翰一書 4:16 少了半節

```
簡體： 而神对我们的爱，我们已经明白，而且相信了。
繁體： 而神對我們的愛，我們已經明白，而且相信了。神就是愛，那住在愛裡的，就住在神裡面，神也住在他裡面。
```

簡體版缺少「**神就是愛，那住在愛裡的，就住在神裡面，神也住在他裡面。**」
——新約中最常被引用的句子之一，整句不見了。

## 二、整節缺失（7 節）

**繁體版缺少（3 節）**

- `以弗所书 3:16` — 另一版作：我求父：照着他丰硕的荣耀，借着他的灵，<note:参2.18注，加4.6注，>用权能使你们内在的人坚强起来，
- `彼得前书 3:11` — 另一版作：还要避恶行善， 觅求和睦， 紧追不舍。
- `彼得前书 3:12` — 另一版作：因为主慈目眷顾义人， 侧耳俯听他们的呼声， 但主跟造孽者作对。<note:诗34.12-16>

**簡體版缺少（4 節）**

- `马可福音 6:10` — 另一版作：還說：“你們無論到哪裡，進了一家，就應借宿在那家，直到離開那裡。
- `马可福音 6:11` — 另一版作：若有甚麼地方不歡迎你們，不肯聽你們的，你們離開那地方的時候，要把腳上的塵土跺落，見證他們的錯。”
- `马可福音 6:8` — 另一版作：他叮囑他們說：“上路只帶一根手杖，其餘甚麼都不帶，麵餅、皮口袋一律不帶，腰帶裡連銅錢也不放。
- `马可福音 6:9` — 另一版作：可以穿鞋，但不必穿兩件束腰外衣。”

## 三、另有 3 節經文長度明顯不符

**`以弗所书 3:15`**

```
繁體： 天上地上一切家族的名字都是起源於父，<note:參4.6、16>我求父：照着他榮耀的豐富，藉著他的靈，<note:參2.18註，加4.6註，>用權能使你們內在的人堅強起來，
簡體： 天上地上一切家族的名字都是起源于父，<note:参4.6，>
```

**`彼得前书 3:10`**

```
繁體： 因為：誰想享受人生，過好日子，就得勒住舌頭不出惡言，管住嘴唇不沾詭詐。11還要避惡行善，覓求和睦，緊追不捨。12因為主慈目眷顧義人，側耳俯聽他們的呼聲，但主跟造孽者作對。<note:詩34.12-16>
簡體： 因为：谁想享受人生， 过好日子， 就得勒住舌头不出恶言， 管住嘴唇不沾诡诈。
```

**`提摩太后书 3:15`**

```
繁體： 而且你自幼便明白神聖的經典，這些經書能夠使你長智慧，而憑著基督耶穌裡的“信”可以得著救恩。<note:參加2.16註，3.11註。>
簡體： 这些经书能够使你长智慧，而凭着基督耶稣里的“信”可以得着救恩。
```

其中 `以弗所書 3:15` 與 `彼得前書 3:10` 是繁體版把下一節併了進來，
與第四節所述同一成因。

## 四、下一節的節號與經文被吞進上一節

繁體版 **117 節**、簡體版 **115 節**。上一節結尾直接接著
下一節的號碼與內容，中間沒有斷開。例如：

```
彼得前書 3:10： 因為：誰想享受人生，過好日子，就得勒住舌頭不出惡言，管住嘴唇不沾詭詐。11還要避惡行善，覓求和睦，緊追不捨。12因為主慈目眷顧義人，側耳俯聽他們的呼聲，但主跟造孽者作對。<note:詩34.12-16>
```

讀者查 3:11、3:12 會查不到，因為它們的內容在 3:10 裡面。

## 五、僅註釋不同、經文相同（4 節，供參考）

這幾節的經文本身兩版一致，只是 `<note:>` 註釋一版有一版無，
列出以免被誤認為經文缺失：

- `以弗所書 3:12`、`使徒行傳 8:5`、`路加福音 9:17`、`路加福音 9:46`

## 六、YsWords 已自行修正的部分

只更動編號與合併，**未改動任何經文文字**：

- `馬太福音 16:13` 原被標成 `16:3`，另有一個標成 `16:1` 的空行。
  因此該節查不到，而 `16:3` 會回傳兩段互相矛盾的經文。
  依簡體版對照更正後，該章恢復為 1–28。
- `使徒行傳 15:16` 原被拆成兩行、共用同一節號，依簡體版合併為一節。
